# สถานการณ์ที่ 2: คำตอบ

## โจทย์

น้อง Junior Developer ในทีมได้รับมอบหมายให้ทำ API สำหรับดึงรายงานยอดขาย ซึ่งประเมินเวลาไว้ 2 วัน แต่น้องทำมา 4 วันแล้วยังไม่เสร็จ น้องมีอาการเครียดและบอกคุณว่า "หนูไม่รู้ว่าทำไมดึงข้อมูลแล้วมันค้าง บางทีก็เจอ Error 500 หนูหาจุดพังไม่เจอเลย"

---

## คำถาม

ในฐานะรุ่นพี่ SA (Technical Mentor) อธิบายขั้นตอนที่คุณจะเข้าไป "ช่วยเหลือและโค้ชน้อง (Approach)" โดยที่คุณจะไม่ไปแย่งคีย์บอร์ดมาพิมพ์แก้โค้ดให้เอง คุณจะมีวิธีตั้งคำถาม สอนวิธี Debug หรือพาน้องไล่ Logic อย่างไรเพื่อให้เขาแก้ปัญหาได้ด้วยตัวเองและเก่งขึ้น?

**คำตอบ:** อย่างแรกก็จะบอกน้องก่อนว่าโอเคใจเย็นๆเดี๋ยวพี่ช่วยดู น้องจะได้รู้สึกว่าไม่ได้ติดอยู่ตรงนี้คนเดียว ต่อไปก็จะให้น้องช่วยเล่า flow api เส้นนี้ให้ฟังดูว่าน้องเข้าใจแบบไหน และจะได้รีเช็คความเข้าใจของเราไปพร้อมกัน อย่างต่อไป จะสอนน้องให้ลองรันเงานเป็นท่อนๆ ดูว่าจุด เกิดปัญหาเกิดจากตรงไหนเช่น เส้นนี้ ขั้นแลกเรียกอะไร ไปรองเรียกขั้นแรกก่อนว่าผ่านมั้ย แล้วไล่ลงมา ที่นี้น้องจะได้ทวนทั้ง flow api เส้นนี้ logic ในแต่ละจุดว่าจะได้ข้อมูลมาเขาอะไรมาจากไหน
