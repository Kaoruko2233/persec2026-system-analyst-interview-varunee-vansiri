# สถานการณ์ที่ 3: คำตอบ

## โจทย์

บริษัทจัดแคมเปญแจกคูปอง 100 สิทธิ์ โดยมีผู้ใช้กดเข้ามาพร้อมกันหลักหมื่นคนในเวลา 12.00 น.

---

## คำถาม

คุณจะออกแบบ Architecture และ Logic การทำงานอย่างไร เพื่อไม่ให้ Database ล่ม และป้องกันการแจกคูปองเกิน (Overbooking)?

**คำตอบ:** อ้างอิงจาากสถานการณ์ที่ 1 คือสามารถใช้ Architecture กับ Logic เดียวกันได้คือ
1. หลังจากที่เข้ามาแล้ว ระบบจะดึงข้อมูลที่ใช้บ่อยๆออกมาก่อน ระหว่างนั้นจะคัดที่เป็นบอททิ้ง
2. ต่อมาจะส่งต่อเข้ารอคิวเพื่อโหลดส่งต่อเข้าเซอร์วิส
3. พอโหลดส่งต่อเขาเซอร์วิสแล้ว ในนั้นพจะมีเรียมคอยคัดว่าผ่านไม่ผ่าน
4. ถ้าผ่านจะส่งไปรอคิวลงฐานข้อมูล
