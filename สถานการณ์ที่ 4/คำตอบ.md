# สถานการณ์ที่ 4: คำตอบ

## โจทย์

หากคุณพบว่ามีคนฝัง API Key หรือ URL ของ 3rd-party ไว้ใน Source Code ตรงๆ (Hardcode)

---

## คำถาม

คุณจะอธิบายผลกระทบที่จะตามมาให้เขาฟังอย่างไร และจะให้เขาแก้วิธีเก็บ Key อย่างไรให้ถูกต้อง?

**คำตอบ:** ผลกระทบถ้าให้เข้าใจง่ายเหมือนเรามตู้เซฟอยู่ตู้นึงแล้วเราเอากุญแจตู้เซฟไปวางไว้บนตู้ ใครมาเห็นก็หยิบเปิดได้ง่ายๆ ซึ่งข้อมูลอาจจะรั่วหรืออะไรก็ตามในตู้จะกลายเป็นของสาธารณะ และทางแก้จากที่ไปคนมาคือ เราต้องเอากุญแจนั้้นไปฝากไว้ที่อื่น โดยเราแค่บอกว่าไปเอากุญแจจากไหน ที่ทที่เอาไปฝากไว้ก็พวก aws ที่เขาจะต้องเช็กก่อนว่ามีิสิทธิ์เข้าถึงกุญแจมั้ยถ้ามีก็เอาไปถ้าไม่มีก็ไม่ให้
