# สถานการณ์ที่ 1: คำตอบ

## โจทย์

บริษัทกำลังจะจัดแคมเปญ "Flash Sale" แจกโค้ดส่วนลด 1,000 สิทธิ์ โดยจะเปิดให้กดพร้อมกันเวลา 12:00 น. คาดว่าจะมีผู้ใช้งาน (Traffic) เข้ามาพร้อมกันบนระบบทั้ง Web และ Mobile App ประมาณ 50,000 คนภายใน 5 นาทีแรก

---

## ข้อ 1

**คำถาม:** ในฐานะ SA ให้ออกแบบ High-Level System Architecture สำหรับระบบนี้ คุณจะใช้ Tech Stack หรือ Component ใดบ้าง (เช่น Database, Cache, Message Queue ฯลฯ) เพื่อให้ระบบไม่ล่ม?

**คำตอบ:** ตาม flow ถ้าเป็น 
1. CDN (Content Delivery Network คล้ายกับ Cache) + WAF (Web Application Firewall ใช้ดักบอท) + Waiting Room อาจจะใช้ Cloudflare
2. Load Balancer อาจจะใช้ AWS ALB / Nginx กระจายโหลดและทำ Health Check
3. Redis
4. Message Queue ใช้เป็น Apache Kafka หรือ Amazon SQS
5. Database ใช้เป็น PostgreSQL 

---

## ข้อ 2

**คำถาม:** คุณจะออกแบบ Logic อย่างไรเพื่อแก้ปัญหา Concurrency (Race Condition) เพื่อป้องกันไม่ให้คนกดรับโค้ดส่วนลดซ้ำซ้อนหรือแจกโค้ดเกิน 1,000 สิทธิ์?

**คำตอบ:** ให้มีการเช็คซ้ำทั้งตอนที่เรียก Redis Lua script และตอนที่ insert ลง db และมีการตัด code ว่าอันไหนถูกใช้ไปกับใครแล้วบ้างเพื่อเช็คจำนวน code ที่เหลือที่แจกได้
